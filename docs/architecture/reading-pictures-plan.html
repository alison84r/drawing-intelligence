Drawing Intelligence · reading pictures inside a drawing

Three readers, and a value is trusted only when two agree

One model on its own will sometimes misread a digit, and nobody can tell when. So no single reader decides. This is the plan for making that hold on any customer drawing.

A value from a picture is filled in automatically only if two independent readers give the same text. Otherwise a person decides, with the picture beside it.

Where AI is used

  • Title block or table saved as a picture
  • Tolerance table in an unusual layout
  • Sorting notes: which are inspected, which are general
  • Later: scanned drawings

Where AI is never used

  • Dimensions and GD&T on a CAD drawing: the exact text is already there
  • Pass or fail decisions
  • Anything written to the report without a person or a second reader

What makes it hold up

  • A fixed test set of real crops with known answers; accuracy is measured before any change ships
  • At the customer the same model runs on their machine; nothing leaves the building
  • If the model is unavailable the app works exactly as before
