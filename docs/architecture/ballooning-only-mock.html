Ballooning only by default; measuring as an option

The app reads the drawing. Measuring the part is a second job that some customers do elsewhere. So the job ends at Check unless you switch measuring on.

1 · The steps across the top

Ballooning only · default
✓Read 2Check 52 / 77 3Report Ballooning+ Measure

Three steps. When every balloon is confirmed, the job is done and Report lights up.

With measuring · optional
✓Read ✓Check 77 / 77 3Measure 0 / 77 4Report Ballooning+ Measure

Four steps, exactly as today.

The switch sits at the right end of the step bar. It is saved with the inspection and can be changed at any time; nothing is lost either way.

Rules

  • New inspections start as ballooning only. Existing ones that already hold results open with measuring on.
  • Switching on adds the Measure step; confirmed balloons become "To measure".
  • Switching off hides results but keeps them stored; switching on again brings them back.
  • The table gets its Result column only with measuring on.
