Where I agree

  • Regions first. A reader should know it is looking at a tolerance table, not guess from loose words.
  • Views matter. A detail at 2:1 has its own scale. Today the scale check assumes one scale per sheet.
  • Different readers for different regions. Text, OCR and a vision model each have a place.

Where I push back

  • The POC does not identify views, tables or title blocks. It extracts lines, hidden lines, arcs and slots, with stable ids, and highlights them. Useful ideas, not the segmentation.
  • OCR only where there is no text. On a CAD-exported PDF the text layer is exact. OCR over it would add errors.
  • No detector model as the backbone for vector drawings. Rules are exact and explainable there. A model earns its place on scans.

What I would take from the POC

  • Hidden-line detection by dash pattern. We do not separate dashed lines yet.
  • Slot grouping. A feature made of several primitives treated as one.
  • Stable ids from content. Already adopted.
  • It renders with a library whose licence does not suit shipping, so the code is a reference, not a dependency.
